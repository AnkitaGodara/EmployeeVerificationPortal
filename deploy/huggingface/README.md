# Employee Verification Portal

Full-stack demo: sign in, upload or capture a photo, and a CNN recognises the employee and shows
their access level and allowed zones. A RAG assistant (FAISS + BM25 + LLM) answers policy questions
with citations.

Source code: https://github.com/utakarshchoudhary282-bit/AI-Based-Face-Recognition-System
